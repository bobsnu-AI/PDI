# 밥스누 PDI 웰니스 솔루션

## 프로젝트 개요
- **이름**: 밥스누 PDI 웰니스 솔루션
- **목적**: 그린바이오 기반 맞춤형 웰니스 솔루션 사업화 - PDI(Phytoceutical Dietary Index) 기반 식단 평가 및 제품 추천 서비스
- **핵심 기능**: 식단 입력 → 파이토케미컬 분석 → PDI 점수 산출 → 맞춤 제품·식단 추천

## 서비스 URL
- **개발 서버**: http://localhost:3000
- **플랫폼**: Cloudflare Pages (Hono Framework)

## 주요 기능

### PDI 평가 엔진
- McCarty (2004) 원식 기반, 한국형 수정 PDI 계산
- PRF(파이토케미컬 풍부 식품) 칼로리 비율로 점수 산출
- 목표치: 40% (Gamba et al. 2023, CoLaus 코호트 n=3,879 근거)
- 차류 특별 가점, 알코올 제외 처리

### 사용자 흐름
1. **프로필**: 성별·나이(숫자)·키·체중(필수) + 허리둘레·이전 체중·활동량·알레르기 → 기준 칼로리(EER)·BMI 미리보기
2. **식습관 입력**: 10문항 설문만으로 PDI 산출 가능(음식 기록 불필요) 또는 끼니별 식사 기록(정확, 인분 선택) — 기록이 있으면 기록 우선
3. **관리 목표**: 체중 관리(기본) + 장 건강·혈당 관리·뼈 건강·피로 회복 추가 선택
4. **결과**: 입력 방식에 따라 보여주는 지표가 다릅니다 (아래 「설문과 식사 기록의 차이」)
5. **구독 세트**: 두유·파이토100·프로틴바 수량을 정하면 할인율·결제액이 바로 계산됩니다
6. **식단 추천받기**: 정한 구독 구성으로 30일 식단을 계산합니다 (버튼을 눌러야 실행 · 약 1초).
   수량을 바꾸면 「구성이 바뀌었습니다 → 다시 추천받기」로 안내하고 그 구성으로 다시 최적화합니다
7. **실천 기록·모니터링**: 끼니별 체크, 체중 기록 → 목표 재조정

### 설문과 식사 기록의 차이 — 보여주는 지표가 다릅니다
설문은 「무엇을 얼마나 **자주**」만 묻습니다. 밥을 몇 공기 먹는지처럼 **섭취량**은 묻지 않으므로,
양에 직접 비례하는 값(칼로리·나트륨·당류)은 신뢰할 수 없습니다. 그래서 지표를 나눠 보여줍니다.

| 지표 | 설문 | 식사 기록 | 이유 |
|---|---|---|---|
| **PDI** | ✅ | ✅ | PRF 칼로리 ÷ 총 칼로리 — **비율**이라 양 오차에 둔감 |
| **파이토케미컬 계열 구성** | ✅ | ✅ | 어떤 계열을 먹었는지는 식품 구성으로 판정 |
| **단백질** | ✅ (예측) | ✅ | 고기·생선·달걀·콩 문항에서 추정 |
| 섭취 칼로리 | ❌ | ✅ | 설문으로는 섭취량을 알 수 없음 |
| 식이섬유 | ❌ | ✅ | 〃 |
| 파이토케미컬 점수(100점) | ❌ | ✅ | mg ÷ 기준량(DRV) — 양 의존 |
| PFS 식단 점수 | ❌ | ✅ | 나트륨·당류·포화지방이 점수의 절반 — 양 의존 |
| 칼로리 초과 경고 | ❌ | ✅ | 〃 |

설문 조합 59,049가지를 전수 조사한 결과: 섭취 칼로리 483–2,883 kcal, 나트륨 462–6,632 mg
(한국 성인 실제 분포 1,200–3,500 kcal 대비 해상도가 낮음). PDI는 28.6–91.6% 로 구성 차이를 잘 가려냅니다.

설문 결과 화면에서는 이 사실을 안내하고 「식사 기록하고 전체 분석 받기」 버튼으로 유도합니다.

### 체중 유형 · 권장 영양 섭취량 (`products.js`)
- BMI 구간: 저체중 / 정상(18.5–22.9) / 과체중(23–24.9) / 비만(25–29.9) / 고도비만(30+) — 엑셀 Sheet3 기준
- 목표 칼로리 = EER + 체중 유형별 조정(저체중 +300 / 정상 0 / 과체중 −400 / 비만 −500 / 고도비만 −750, EER 25% 이내로 제한)
- 표준 체중(BMI 22), 예상 주당 체중 변화(체지방 1kg ≈ 7,700kcal)
- 권장 섭취량: 탄단지 에너지적정비율, 식이섬유 12g/1,000kcal, 당류·포화지방·나트륨 상한 (KDRI 2020)

### 구독 세트 · 할인 정책 (`products.js` · 엑셀 Sheet3)
- 제품 마스터: 두유 A~I(27,000 / 37,500원) · 파이토100 「가」(42,000원) · 프로틴바 「나」(20,000원) · 추가 구성품 1~4(38,400 / 40,000원)
- **영양성분은 「밥스누 제품소개서_20260615.pptx」 표시란 실측값** (1회 제공량 기준, 라벨 미표시 항목은 0)
- 알레르기 유발물질도 제품소개서 원재료명 기준으로 기재 — 두유 전 품목 대두, 프로틴바는 대두·땅콩·호두, 파이토100은 토마토
  (파이토100은 원재료에 유기농 약콩이 있으나 **대두 알레르기 환자도 섭취 가능**)
- **파이토케미컬은 원재료명으로 추정**합니다 (제품별 실측 분석값 확보가 어려워)
  - 약콩 기준값 + 제품소개서 「원재료명 및 함량」에 적힌 원재료의 파이토케미컬을 합산
  - 함량 미공개 원료는 공개된 총함량으로 원물 중량을 환산해 균등 분배
  - 원재료 추정 열량이 라벨 열량을 넘으면 라벨에 맞춰 축소 (파이토100: 368 → 110 kcal)
  - 결과 계열 수: 오리지널 약콩두유 4 · 쌀눈 약콩100 8 · 슈퍼그린 9 · 파이토100 9 · 프로틴바 9
  - 파이토100은 약콩 기준값을 쓰지 않고 유기농 생식 21종 원재료만으로 계산
- 수량 조정형 구독: 두유 N개 + 파이토 N개 + 프로틴바 N개
- 할인율: 두유2·파이토2·프로틴바3 → **20%** / 두유1·파이토1·프로틴바2 → **15%** / 커스터마이징 1개 → 5%, 2개 이상 → 10% / 추가 구성품 포함 시 **+5%p**
- 정가 = 단가 합계. 엑셀 프리셋 정가와 일치: 두유2+파이토2 = 138,000원 · 두유1+파이토1 = 69,000원
- **체중 관리자 추천 룰테이블 32행 적재**: PDI 4구간 × 체중 유형 2 × 연령 4 → 연령별 추천 두유,
  통곡물·채소 부족 시 파이토/프로틴바, 단백질 부족 → C, 장 건강 → D(두유 대체),
  혈당·뼈건강·피로회복 → 추가 구성품 1·2·3·4

### 30일 맞춤 식단 — 다목적 최적화 (`mealplan.js`)
`Diet_class.py` / `load_data.py` / `optimizer_base.py` / `spea2_optimizer.py` / `evaluation_function.py` 를 JS로 포팅 (SPEA2 알고리즘)
- **한 끼 구성 항목**: 밥 · 국 · 메인반찬 · 김치 · 부수반찬
  - 분류는 **음식 분류코드**(`foodclass.js`)로 판정합니다 — 레시피 14,714개 전부 매핑
  - **아침은 3품** (밥·국·메인반찬), 점심·저녁은 5품 — 하루 총열량을 목표에 맞추기 위함
  - **밥 양은 0.6 / 0.8 / 1공기** 중에서 최적화가 직접 고릅니다 (한 공기 ≈ 300 kcal 로 열량 조절 효과가 가장 큼)
- **밥스누 제품 배치** — 구독한 수량을 30일에 전부 소진합니다
  - **끼니 대체**: 저녁 우선, 하루 1끼. 조합 A =(두유+파이토100) · 조합 B =(두유+프로틴바+과일)
  - **곁들임**: 남는 제품은 아침 → 점심 → 간식 순서로 일반 식단에 추가
  - 끼니를 2개 이상 대체하면 제품 1끼가 ~260 kcal 라 남은 한 끼로 목표 칼로리를 채울 수 없어, 대체는 하루 1끼로 제한
- **평가 점수 4개** (모두 높을수록 좋음, 0–100): 영양 균형(KDRI 기준 대비) · PDI 달성도(목표 40%) · 메뉴 다양성 · 메뉴 궁합
- 같은 프로필이면 같은 식단이 나오도록 난수 시드를 고정 → 30일 실천 기록이 유지됨
- 실측: 30일 · 계산 60회 반복 · 약 0.8초 (브라우저 단독 실행)

### 실천 기록 · 체중 모니터링 (`tracker.js`)
- 끼니별 **먹었어요 / 다른 음식 / 안 먹음** 기록. 「다른 음식」은 레시피·단품 식재료를 **인분(0.5~3)** 과 함께 입력
- 계획 대비 실제 섭취 칼로리·PDI, 식단 실천율
- 체중 기록 → 최소제곱 추세선(kg/주) → 계획 추세와 비교
- **목표 재조정**: 조정량 = (실제 − 계획 주당변화) × 7,700 ÷ 7, 1회 ±300kcal 이내, 하한 max(1,200, EER×0.7) → 적용 시 식단 재생성
- 저장: `localStorage`(키 `bobsnu-pdi-v1`) — 단일 기기 한정

### PFS 식단 영양 점수 (PDI·파이토 점수와 별도)
- `diet_food_scoring.py`의 `PFS_function`을 JS로 포팅 (`public/static/pfs.js`)
- 입력: 성별·나이·신장·체중·이전 체중(선택)·활동량 → KDRI 2020 에너지필요추정량(EER)
- Basic_score: 9개 영양소(탄수화물·단백질·지방·식이섬유 가점 / 콜레스테롤·당류·포화지방·트랜스지방·나트륨 감점), 최대 4.0
- ED_score(에너지 밀도), SI_score(포만 지수)
- 체중 추세별 총점: 감량기 Basic+ED · 증가기 Basic+ED+SI · 유지기 Basic
- 1일 식단 전체(기준치 ×1.0) + 음식별(본식 ×0.3·반찬 ×0.2·간식 ×0.1) 점수
- 식재료 DB에 kcal만 있어 영양성분은 식재료명 규칙·식품군 프로필로 추정 (`INGREDIENTS[x].nut`에 실측값 추가 시 우선 사용)
- **Basic 점수는 0~4 척도가 아닙니다**: 가점 4종(탄수화물·단백질·지방·식이섬유, 최대 4.0)에서
  감점 5종(콜레스테롤·당류·포화지방·트랜스지방·나트륨)을 뺀 값이라 음수가 될 수 있습니다.
  화면에 `Basic 0.24 (가점 3.9 − 감점 3.7)` 형태로 내역을 함께 표시합니다
- **절임·데침용 소금 보정**: 절임용 소금은 씻어내고 데치는 물의 소금은 버리므로 잔류율 20%만 반영합니다.
  이 보정 없이는 김치 한 가지로 나트륨이 1,100 mg 넘게 과대 계상됩니다 (보정 후 설문 기준 3,148 mg — 국민건강영양조사 평균 수준)

### 음식 분류체계 (`foodclass.js` · 자동 생성)
- 분류코드 = **대분류 문자 + 중분류 2자리 + 소분류 2자리** (예: `A0102` = 주식 · 밥류 · 잡곡밥)
- 대분류: 주식_A · 국·탕류_B · 반찬류_C · 양념류_D · 간식·후식·음료_E · 단품_F · 가공식품류_G
- 레시피 14,714개 · 분류코드 240종
- 생성: `node scripts/build-foodclass.mjs` (입력은 `scripts/data/` 의 음식·레시피 / 음식 분류체계 엑셀)
- 구성 항목 매핑
  | 구성 항목 | 분류코드 | 후보 수(열량대 내) |
  |---|---|---|
  | 밥 | A0101·A0102·A0104·A0112·A0116 (쌀밥·잡곡밥·채소밥·혼합영양밥·기타밥) | 343 |
  | 국 | B05·B06·B07·B08 (국·탕·스프·찌개·전골) | 2,478 |
  | 메인반찬 | C09·C10·C11·C12·C13 (찜·구이·전·볶음·조림) | 3,229 |
  | 김치 | C17 | 98 |
  | 부수반찬 | C15·C16·C19 (무침·샐러드·장아찌·절임) | 767 |
- 제외: C14 튀김류(다이어트 부적합) · C18 젓갈류(고나트륨) · A02 빵류 · A03 면류 · A04 죽류 ·
  볶음밥·비빔밥·덮밥·김밥 등 한 그릇 요리 · E 간식·음료 · G 가공식품

## 용어
| 용어 | 뜻 |
|---|---|
| PDI | Phytoceutical Dietary Index. 파이토케미컬 풍부 식품(PRF)이 전체 섭취 칼로리에서 차지하는 비율(%) |
| PRF 식품 | 통곡물·두류·채소·과일·견과·식물성오일·차류 |
| 구성 항목 | 한 끼를 이루는 자리 — 밥 · 국 · 메인반찬 · 김치 · 부수반찬 |
| 분류코드 | 음식을 대분류·중분류·소분류로 나눈 5자리 코드 (예: A0102 = 주식 · 밥류 · 잡곡밥) |
| 끼니 대체 | 한 끼를 밥스누 제품으로 완전히 바꾸는 것 (저녁 우선, 하루 1끼) |
| 곁들임 | 일반 식단에 밥스누 제품을 하나 추가하는 것 (아침 → 점심 → 간식 순서) |
| EER / 기준 칼로리 | 에너지필요추정량. 현재 체중을 유지하는 데 필요한 하루 칼로리 (KDRI 2020) |
| 목표 칼로리 | 기준 칼로리에 체중 유형별 조정을 더한 값 — 식단이 맞춰야 하는 하루 칼로리 |
| PFS 식단 점수 | 9개 영양소의 기준 대비 가·감점으로 산출하는 별도의 식단 영양 점수 |

## 미구현/향후 과제
- **제품별 파이토케미컬 실측 분석값** — 확보가 어려워 원재료명 기반 추정으로 운영 중
  (`products.js` 의 `phytoFrom` · 실측값이 들어오면 `productPhytos()` 를 교체)
- **식재료 단가 DB** — 비용 최적화는 하지 않기로 결정 (4개 평가 점수로 운영). 단가표가 들어오면 `evaluate_cost` 복원 가능
- **칼슘 함량 DB** — 식재료 쪽에 칼슘 값이 없어 칼슘 부족 판정은 제외. 룰테이블의 칼슘 열(E/H)은 전사만 해둔 상태
  (제품 쪽 칼슘은 제품소개서 라벨값을 `nut.calcium` 에 보유 — A 130 / E 210 / H 230 / 칼마디케이 300 mg)
- 사용자 계정 및 기기 간 동기화 (Cloudflare D1) — 현재 localStorage 단일 기기
- 실제 파이토케미컬 DB 연동 (Phenol-Explorer, USDA Flavonoid DB)
- 한국 식품 DB 매핑 확장 (국가표준식품성분표)
- 사진 인식 기반 식단 입력
- B2B 기관 관리자 대시보드
- 제품별 **파이토케미컬 실측값** — 현재 약콩·파이토100 기준값을 모든 제품에 공통 적용 (`phytoBase`)
- 설문을 서울대 식이평가 서빙 기준(우수·보통·부족·개선 필요)으로 환산 (엑셀 Sheet3 65행 메모) — 현재 10문항은 대표 음식으로 환산해 PDI 계산에 사용 중
